## 5. Backend Search Proxy Configuration (`SEARCH_PROXY_ENDPOINT`)

Listen to Eve enforces a secure, provider-independent search architecture where external search provider secrets (Tavily, Serper, Brave, Gemini Grounding) remain strictly on the backend. The client communicates via the `/api/search` endpoint.

The endpoint is resolved in the following priority order:
1. Runtime setting stored in app preferences (via in-app Settings screen)
2. Compile-time environment variable: `--dart-define=SEARCH_PROXY_ENDPOINT=...`
3. Default fallback: `/api/search`

### Network Scenarios

#### Scenario A — Android Emulator (Backend running locally on developer computer)
- The Android Emulator routes the host computer via `10.0.2.2`.
- **Default behavior**: When `SEARCH_PROXY_ENDPOINT` is left at default `/api/search`, `BackendProxySearchTransport` automatically resolves relative paths on Android to `http://10.0.2.2:3000/api/search`.
- **Explicit flag**:
  ```bash
  --dart-define=SEARCH_PROXY_ENDPOINT=http://10.0.2.2:3000/api/search
  ```

#### Scenario B — Physical Android Device (Backend running on developer computer)
- Physical phones connect over Wi-Fi/LAN. `10.0.2.2` will **not** work on a physical device.
- Ensure the backend server binds to all network interfaces (`0.0.0.0:3000`).
- Locate your development machine's local LAN IP (e.g. `192.168.1.50` via `ifconfig` or `ipconfig`).
- **Explicit flag**:
  ```bash
  --dart-define=SEARCH_PROXY_ENDPOINT=http://192.168.1.50:3000/api/search
  ```

#### Scenario C — Deployed Backend (Cloud Run / VPS)
- Use your HTTPS-secured public backend URL:
  ```bash
  --dart-define=SEARCH_PROXY_ENDPOINT=https://your-backend-domain.com/api/search
  ```

## 6. Backend Server Startup

Before testing the web search intelligence pipeline on an Android emulator or physical device, ensure the companion backend proxy is running from the repository root:

```bash
# In the root repository directory:
npm run dev
```

The server binds to `0.0.0.0:3000` and serves both the development UI and `/api/search`.

## 7. Local Build & Run Instructions

All commands below should be run from the `flutter_source/` directory:

```bash
cd flutter_source
```

### Step 1: Clean and Fetch Dependencies
```bash
flutter clean
flutter pub get
```

### Step 2: Code Analysis & Unit Tests
```bash
flutter analyze
flutter test
```

### Step 3: Build Debug APK
For Android Emulator:
```bash
flutter build apk --debug
```

For Physical Android Device (replace LAN IP):
```bash
flutter build apk --debug --dart-define=SEARCH_PROXY_ENDPOINT=http://192.168.1.50:3000/api/search
```

### Step 4: APK Output Location
The compiled debug binary will be created at:
```
flutter_source/build/app/outputs/flutter-apk/app-debug.apk
```

### Step 5: Install & Run on Connected Device / Emulator
To run directly with live console logs:
```bash
# List available devices
flutter devices

# Run directly on emulator
flutter run -d emulator-5554 --debug

# Or run with explicit proxy endpoint
flutter run --debug --dart-define=SEARCH_PROXY_ENDPOINT=http://10.0.2.2:3000/api/search
```

Or install the prebuilt APK manually using `adb`:
```bash
adb install -r build/app/outputs/flutter-apk/app-debug.apk
```

## 8. Runtime Smoke-Test Checklist

Once the APK is launched on device, verify the intelligence pipeline in the native app:

- [ ] **Test A: Normal Conversation**
  - Prompt: `"Hi Eve, how are you?"`
  - Expected: Natural conversational response; no web search is triggered; no internal debug or tool language is shown.
- [ ] **Test B: Timeless Knowledge**
  - Prompt: `"What is photosynthesis?"`
  - Expected: Direct explanation from model knowledge base; no external web search triggered.
- [ ] **Test C: Memory Creation & Retrieval**
  - Prompt: `"My name is Chris. Remember that."`
  - Verification Prompt: `"What is my name?"`
  - Expected: Recalls `"Chris"`. Restart the app completely and re-ask `"What is my name?"` to confirm SharedPreferences persistence survives restart.
- [ ] **Test D: Current Information Search**
  - Prompt: `"What's the latest news today?"` or `"Who is the current president of South Africa?"`
  - Expected: Automatic web search triggers via `/api/search`; normalized factual context is injected; Eve provides an up-to-date answer without displaying raw JSON or URLs.
- [ ] **Test E: Afrikaans Support**
  - Prompt: `"Wat is die nuutste nuus vandag?"`
  - Expected: Search triggers with `language: 'af'`; response is in natural Afrikaans.
- [ ] **Test F: Character Switching**
  - Switch: Eve → Ara → Leo → Rex → Sal.
  - Expected: Active persona updates with distinct voice, status, and system prompt; no hard-coded "Eve" references appear on other characters.
- [ ] **Test G: Provider Independence**
  - Settings: Switch between Gemini (`gemini-3.6-flash`) and xAI (`grok-4.6`).
  - Expected: Memories, chat history, and web search remain intact across provider switches.

## 9. Network & Security Architecture Notes

- **Cleartext Traffic**: `android:usesCleartextTraffic="true"` is enabled in `AndroidManifest.xml` specifically to support local HTTP communication with `http://10.0.2.2:3000` and LAN IP addresses during development. For production builds with an HTTPS backend, this setting should be removed or constrained using a network security configuration (`res/xml/network_security_config.xml`).
- **Zero Client-Side Search Secrets**: The Flutter client contains no API keys for Tavily, Serper, Brave, or Gemini Grounding. All provider keys reside strictly on the server/proxy.
- **Provider API Keys**: Gemini and xAI keys configured by the user in the in-app Settings screen are stored locally in device private storage (`SharedPreferences`) and never committed to version control.
- **No Secrets in Repository**: `.env` and `local.properties` are strictly excluded in `.gitignore`.
